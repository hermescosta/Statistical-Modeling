# Statistical-Modeling
Classificação supervisionada para prever a adesão de clientes a depósito a prazo em campanhas de telemarketing bancário (base Bank Marketing). Regressão logística e random forest implementadas do zero em R base, com EDA, seleção de variáveis por correlação, tratamento de desbalanceamento, tuning por otimização bayesiana e avaliação em teste.
